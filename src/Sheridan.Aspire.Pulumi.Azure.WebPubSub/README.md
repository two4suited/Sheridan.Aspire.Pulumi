# Sheridan.Aspire.Pulumi.Azure.WebPubSub

_Web PubSub_ — part of [Sheridan.Aspire.Pulumi](../../README.md).

`Sheridan.Aspire.Pulumi.Azure.WebPubSub` ports `Aspire.Hosting.Azure.WebPubSub`. `builder.AddPulumiWebPubSub("pubsub")` (alias `AddPulumiAzureWebPubSub`) provisions an `azure-native:webpubsub:WebPubSub` with the official Bicep's shape (SKU `Free_F1`, capacity 1, local auth disabled, `aspire-resource-name` tag; outputs `endpoint`, `name`, `id`). `AddHub(name, hubName?)` adds `WebPubSubHub` resources and `AddEventHandler(urlTemplate, userEventPattern, systemEvents)` configures their event handlers; `WithSku(...)` overrides the SKU.

```csharp
var pubsub = builder.AddPulumiWebPubSub("pubsub").WithPulumiStack(azureStack);
pubsub.AddHub("notifications").AddEventHandler("https://example.com/api/{event}", "*", ["connected"]);
builder.AddProject<Projects.MyApi>("api").WithReference(pubsub).WithComputeEnvironment(acaEnv);
```

`WithReference` of the service or a hub grants the compute environment's identity *Web PubSub Service Owner* (the official default); `WithRoleAssignments(pubsub, AzureWebPubSubRole.WebPubSubServiceReader)` replaces it. `ConfigureInfrastructure(infra => infra.WebPubSubService.Set("tls.clientCertEnabled", true))` edits the generated resources (`WebPubSubService`, `Hubs`; see docs/provisioning.md). The service name is auto-generated by the provider.
