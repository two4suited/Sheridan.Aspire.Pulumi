# Sheridan.Aspire.Pulumi.Azure.Search

_Search_ — part of [Sheridan.Aspire.Pulumi](../../README.md).

`Sheridan.Aspire.Pulumi.Azure.Search` ports `Aspire.Hosting.Azure.Search`. `builder.AddPulumiSearch("search")` (alias `AddPulumiAzureSearch`) provisions an `azure-native:search:Service` matching the Bicep the official integration generates: `basic` SKU, 1 partition, 1 replica, `hostingMode: default` and local (key) auth disabled, with outputs `Endpoint` (`https://<name>.search.windows.net`), `Name` and `Id`. The connection string is `Endpoint=<endpoint>`. `WithReference(search)` grants the hosting compute environment's identity *Search Index Data Contributor* and *Search Service Contributor* (the official defaults); `WithRoleAssignments(search, AzureSearchRole.SearchIndexDataReader, ...)` replaces them. `WithSku("standard")` is an addition for choosing another tier, and `ConfigureInfrastructure(infra => infra.SearchService.Set("replicaCount", 3))` edits the generated resource (see `../../docs/provisioning.md`). The service name is auto-generated by the azure-native provider. Not ported: `PublishAsExisting`/`AsExisting`, and a local emulator (the official integration has none).
