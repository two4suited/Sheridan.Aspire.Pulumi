# Sheridan.Aspire.Pulumi.Azure.Storage

Azure Storage (blobs, queues, tables) provisioned by Pulumi, a drop-in for `AddAzureStorage`.

`AddPulumiStorage` provisions a StorageV2 / Standard_GRS / TLS 1.2 account with shared-key access disabled, matching the Bicep the official integration generates.

## Install

```bash
dotnet add package Sheridan.Aspire.Pulumi.Azure.Storage
```

## Usage

```csharp
var builder = DistributedApplication.CreateBuilder(args);

builder.AddPulumiStack("my-app", "dev").WithOrganization("my-org");

var acaEnv = builder.AddPulumiAzureContainerAppEnvironment("aca-env");   // Sheridan.Aspire.Pulumi.Azure.AppContainers

var storage = builder.AddPulumiStorage("storage")
    .RunAsEmulator();   // Azurite for `aspire run`
var blobs = storage.AddBlobs("blobs");
blobs.AddBlobContainer("uploads");
storage.AddQueues("queues").AddQueue("jobs");

builder.AddProject<Projects.MyApi>("api")
    .WithComputeEnvironment(acaEnv)
    .WithReference(blobs);

builder.Build().Run();
```

## Features

- `AddBlobs`, `AddQueues`, `AddTables`, `AddBlobContainer` and `AddQueue` mirror the official API.
- `WithReference(blobs)` (or the queue, table or container resources) grants the compute environment's identity the matching *Storage Blob/Queue/Table Data Contributor* role.
- The storage account name is auto-generated by the azure-native provider. Alias: `AddPulumiAzureStorage`.

## Azurite emulator

`RunAsEmulator` runs Azurite (`mcr.microsoft.com/azure-storage/azurite`, pinned to the tag the official integration uses) in `aspire run` instead of the Pulumi-provisioned account. It has no effect when publishing. The container is started with the same arguments as the official integration (`azurite -l /data --blobHost 0.0.0.0 --queueHost 0.0.0.0 --tableHost 0.0.0.0 --disableProductStyleUrl --skipApiVersionCheck`), so recent `Azure.Storage` SDKs are not rejected with "API version not supported".

```csharp
var storage = builder.AddPulumiStorage("storage")
    .RunAsEmulator(emulator => emulator
        .WithDataVolume()            // or WithDataBindMount(".azurite/storage")
        .WithBlobPort(10000)
        .WithQueuePort(10001)
        .WithTablePort(10002));
```

`configureContainer` receives an `IResourceBuilder<AzureStorageEmulatorResource>` with:

- `WithDataVolume(name?, isReadOnly)` / `WithDataBindMount(path?, isReadOnly)`: persist `/data` between runs (default bind-mount path `.azurite/{storage name}`).
- `WithBlobPort(port)` / `WithQueuePort(port)` / `WithTablePort(port)`: fixed host ports (random otherwise).
- `WithApiVersionCheck(enable = true)`: remove `--skipApiVersionCheck` so Azurite validates the requested API version. Note this differs from the official integration, whose implementation adds the flag when `enable` is `true`, contradicting its documentation.
