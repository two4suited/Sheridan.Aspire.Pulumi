# Sheridan.Aspire.Pulumi.Azure.Storage

_Storage_ — part of [Sheridan.Aspire.Pulumi](../../README.md).

`Sheridan.Aspire.Pulumi.Azure.Storage` ports `Aspire.Hosting.Azure.Storage`. `builder.AddPulumiStorage("storage")` (alias `AddPulumiAzureStorage`) provisions a StorageV2 / Standard_GRS / TLS1_2 account with shared-key access disabled, matching the Bicep the official integration generates. `AddBlobs`/`AddQueues`/`AddTables`, `AddBlobContainer` and `AddQueue` mirror the official API, and `.RunAsEmulator()` runs Azurite locally. `WithReference(blobs)` (or the queue/table/container/queue resources) grants the hosting compute environment's identity the matching *Storage Blob/Queue/Table Data Contributor* role. The storage account name is auto-generated by the azure-native provider.
